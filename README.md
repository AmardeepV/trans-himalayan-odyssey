# Trans-Himalayan Odyssey

A static landing page for a small-group Himalayan motorcycle adventure business. It is ready to publish with GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository and upload these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. GitHub will display the public URL after deployment.

## Before publishing

- Replace the temporary `hello@transhimalayanodyssey.com` email in `contact.html` and `script.js` with your real contact address. The form opens a pre-filled email in the visitor's email app, which keeps it compatible with GitHub Pages.
- Replace the stock photography URLs in `styles.css` with your own Himalayan ride photos. The image blocks are clearly grouped as `.hero-image`, `.card-one`, `.card-two`, `.card-three`, `.manifesto-image`, and `.about-photo`.
- Your host image is stored locally as `assets/rider.jpg`, so it will be included when the site is published.
- Update the itinerary descriptions once the exact routes, inclusions, dates and pricing are decided.

No build step is required: open `index.html` in a browser to preview it locally.
